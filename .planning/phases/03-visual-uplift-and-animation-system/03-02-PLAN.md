    **Step 1: Add data attributes to the grid and card wrappers.**

    On the grid container div (line 47), add `data-glow-grid`:
    Change:
    `<div class="mt-16 grid grid-cols-1 gap-6 md:grid-cols-2 lg:grid-cols-3">`
    to:
    `<div class="mt-16 grid grid-cols-1 gap-6 md:grid-cols-2 lg:grid-cols-3" data-glow-grid>`

    On each card wrapper div (line 49), add `data-glow-card`:
    Change:
    `<div data-reveal="up" data-reveal-delay={String(index + 1)}>`
    to:
    `<div data-reveal="up" data-reveal-delay={String(index + 1)} data-glow-card>`

    **Step 2: Add inline script at the bottom of the file (after the closing `</section>`).**

    ```html
    <script>
      function initGlowGrid() {
        const grid = document.querySelector('[data-glow-grid]');
        if (!grid || window.matchMedia('(pointer: coarse)').matches) return;

        grid.addEventListener('mousemove', (e) => {
          const cards = grid.querySelectorAll('[data-glow-card]');
          for (const card of cards) {
            const rect = card.getBoundingClientRect();
            card.style.setProperty('--mouse-x', `${e.clientX - rect.left}px`);
            card.style.setProperty('--mouse-y', `${e.clientY - rect.top}px`);
          }
        });
      }

      initGlowGrid();
    </script>
    ```

    **Important notes:**
    - The `::before` pseudo-element for the glow effect is defined in `global.css` via `[data-glow-card]::before` (created in Plan 01 Task 2). The script only sets the CSS custom properties.
    - Touch device detection via `window.matchMedia('(pointer: coarse)')` means the mousemove handler is never registered on mobile/tablet (per Claude's discretion recommendation).
    - The `data-glow-card` goes on the wrapper div, not on the Card component itself, because Card.astro renders as `<a>` and the `::before` pseudo-element needs `position: relative` which is set by the `[data-glow-card]` CSS rule in global.css.
    - Content inside the card (text, icons) will render above the glow because Card's slot content has natural stacking. The glow `::before` has `z-index: 1` and `pointer-events: none`.

    Key changes:
    - Remove `hidden` class (breaks transitions — element must be in DOM)
    - Add `flex` permanently (layout always flexbox)
    - Add `-translate-y-full` (hidden state: slides up offscreen)
    - Add `opacity-0` (hidden state: transparent)
    - Add `invisible` (hidden state: not interactable by screen readers)
    - Add `pointer-events-none` (hidden state: not clickable)
    - Add `transition-[transform,opacity,visibility] duration-300 ease-out` (animation)

    **Step 2: Update the openMenu() function in the script.**

    Replace the current toggle logic:
    ```js
    function openMenu() {
      if (!mobileMenu || !hamburgerBtn || !hamburgerIcon || !closeIcon) return;
      mobileMenu.classList.remove('-translate-y-full', 'opacity-0', 'invisible', 'pointer-events-none');
      mobileMenu.classList.add('translate-y-0', 'opacity-100', 'visible', 'pointer-events-auto');
      hamburgerBtn.setAttribute("aria-expanded", "true");
      hamburgerIcon.classList.add("hidden");
      closeIcon.classList.remove("hidden");
      document.body.style.overflow = "hidden";
      mobileCloseBtn?.focus();

    ```

    **Step 3: Update the closeMenu() function in the script.**

    ```js
    function closeMenu() {
      if (!mobileMenu || !hamburgerBtn || !hamburgerIcon || !closeIcon) return;
      mobileMenu.classList.add('-translate-y-full', 'opacity-0', 'pointer-events-none');
      mobileMenu.classList.remove('translate-y-0', 'opacity-100', 'pointer-events-auto');
      hamburgerBtn.setAttribute("aria-expanded", "false");
      hamburgerIcon.classList.remove("hidden");
      closeIcon.classList.add("hidden");

          mobileMenu.classList.remove('visible');
        }
      }, 300);
      hamburgerBtn.focus();
    }
    ```
