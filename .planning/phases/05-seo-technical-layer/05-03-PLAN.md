**Update the sitemap integration in astro.config.mjs (per D-10, D-11, D-12):**

The sitemap config currently has only `filter`. Add a `serialize` callback alongside it. The full sitemap integration becomes:

```javascript
sitemap({
  filter: (page) => {
    try {
      const pathname = new URL(page).pathname.replace(/\/$/, "") || "/";
      if (
        pathname === "/na-mesa-certa" ||
        pathname === "/trintae3" ||
        pathname === "/comunidade-us" ||
        pathname === "/neon-dash"
      ) {
        return false;
      }
    } catch {
      /* keep page */
    }
    return true;
  },
  serialize(item) {
    const pathname = new URL(item.url).pathname.replace(/\/$/, "") || "/";

    /** @type {Record<string, { priority: number; changefreq: string }>} */
    const config = {
      "/": { priority: 1.0, changefreq: "weekly" },
      "/curso-auriculo": { priority: 0.9, changefreq: "monthly" },
      "/mentoria-black-neon": { priority: 0.9, changefreq: "monthly" },
      "/otb": { priority: 0.9, changefreq: "monthly" },
      "/sobre": { priority: 0.7, changefreq: "monthly" },
      "/contato": { priority: 0.7, changefreq: "monthly" },
      "/termos": { priority: 0.3, changefreq: "yearly" },
      "/politica-de-privacidade": { priority: 0.3, changefreq: "yearly" },
    };

    const entry = config[pathname];
    if (entry) {
      item.priority = entry.priority;
      item.changefreq = entry.changefreq;
    }

    return item;
  },
}),
```

NOTE: After Plan 01 modifies astro.config.mjs (removing /otb redirect and /otb from filter), read the file fresh before editing. The filter function will already NOT have /otb. This task only adds the `serialize` callback.

Do NOT import `ChangeFreqEnum` -- use plain string literals `"weekly"`, `"monthly"`, `"yearly"` which are simpler and equally valid for the sitemap protocol.
