## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (components.json present, new-york style) |
| Preset | new-york |
| Component library | Existing Astro landing components (12 reusable sections) |
| Icon library | Lucide React SVG |
| Font | Playfair Display (headings, `font-serif`) + Inter (body, `font-sans`) |

**Phase 5 scope note:** This phase adds zero new design tokens, zero new CSS utilities, and zero new React islands. All visual work uses the established design system from Phases 1--4. The primary visual deliverables are: (1) a new OTB landing page composed from existing components, (2) static OG image SVG templates following brand colors, and (3) invisible structured data (JSON-LD, sitemap, robots.txt).

## OTB Landing Page -- Section Composition

The OTB page uses the standard landing template pattern. Section order follows `curso-auriculo.astro` (no custom sections like mentoria-black-neon's NeonStory/NeonBonus/NeonBio, because OTB JSON lacks `story`, `bonus`, and `bio` fields).

| Order | Component | Data Source | Notes |
|-------|-----------|-------------|-------|
| S1 | `LandingHero` | `name`, `tagline`, `hero`, `type`, `cta` | Mesh gradient bg, gold last-word highlight ("Dubai"), primary CTA + WhatsApp secondary |
| S2 | `PainPoints` | `audience`, `painPoints[3]` | 3-card grid with icons (TrendingDown, Plane, ShieldAlert) |
| S3 | `Pillars` | `pillars[3]` | 3-column layout with icons (Award, Eye, FlaskConical) |
| S4 | `Benefits` | `benefits[7]` | Checkmark list, 7 items |
| S5 | `Differentials` | `differentials[3]` | 2-col grid, glass-card with gold left border. First differential contains Dubai calendar dates |
| S6 | `TestimonialCarousel` | `testimonials[2]` | React island (`client:visible`), drag carousel with autoplay |
| S7 | `FAQ` | `faqs[5]` | Native `<details>`/`<summary>`, 5 items |
| S8 | `LandingCTA` | `name`, `cta` | `glass-card-bright`, final conversion section |
| S9 | `MobileCTABar` | `cta` | Fixed bottom bar on mobile with primary CTA |

**No custom OTB-specific components needed.** The event calendar details (Dubai Oct 18--23, 2026) are already embedded in `differentials[0]` description text and rendered naturally by the existing `Differentials.astro` component. The AMWC schedule appears in `faqs[1]` answer text.

**Layout wrapper:**
```
<Layout
  title="OTB -- MBA Internacional em Dubai com selo MEC | Grupo US"
  description={d.description}
  ogImage="/og/otb.png"
  activeNav="produtos"
  whatsappMessage={d.cta.whatsappMessage}
  hasBottomBar={true}
  breadcrumbs={[
    { name: "Inicio", url: "https://grupous.com.br/" },
    { name: d.name, url: "https://grupous.com.br/otb" }
  ]}
  jsonLd={eventSchema}
>
```

Note: `jsonLd` prop is new -- added to Layout.astro as `Record<string, unknown>` optional prop per RESEARCH.md architecture recommendation.

## Interaction Contract

### OTB Landing Page Interactions

All interactions are inherited from existing components -- no new interaction patterns:

| Interaction | Component | Behavior |
|-------------|-----------|----------|
| Hero mesh gradient | `LandingHero` via `landing-mesh-bg` CSS | 20s infinite drift animation; disabled on mobile and `prefers-reduced-motion` |
| Hero entrance | `LandingHeroEntrance` (`client:visible`) | Spring animation: stiffness 200, damping 25, mass 1 |
| Card hover | `Differentials`, `PainPoints` via `data-reveal` + hover classes | `translateY(-6px) scale(1.01)` on hover; scroll-reveal on enter |
| CTA pulse | `LandingHero` primary button via `gold-pulse-glow` | 3s infinite pulse on gold shadow; disabled on mobile |
| Testimonial carousel | `TestimonialCarousel.tsx` (`client:visible`) | Drag/swipe, 4s autoplay, dot indicators |
| FAQ accordion | `FAQ.astro` via `<details>/<summary>` | Native browser accordion, CSS `grid-template-rows: 0fr -> 1fr` transition |
| Mobile CTA bar | `MobileCTABar.astro` | Fixed bottom position, visible below md breakpoint |
| WhatsApp floating button | `WhatsAppFloatingButton.tsx` (`client:load`) | Scroll-triggered entrance, per-page message from `whatsappMessage` prop |

### Non-Visual Interactions (structured data)

| Element | Behavior | User-Visible? |
|---------|----------|---------------|
| JSON-LD Course (curso-auriculo) | Injected in `<head>` via Layout `jsonLd` prop | No -- search engine only |
| JSON-LD Product (mentoria-black-neon) | Injected in `<head>` via Layout `jsonLd` prop | No -- search engine only |
| JSON-LD Event (otb) | Injected in `<head>` via Layout `jsonLd` prop | No -- search engine only |
| BreadcrumbList (termos, privacidade, otb) | Injected in `<head>` via existing breadcrumbs prop | No -- search engine only |
| Sitemap priorities | Build-time via `@astrojs/sitemap` serialize callback | No -- crawler only |
| robots.txt | Static file in `public/` | No -- crawler only |

## Accessibility Contract

No new a11y patterns needed. OTB page inherits all existing patterns:

| Requirement | Implementation | Source |
|-------------|---------------|--------|
| Single h1 per page | Hero headline in `LandingHero` | `.claude/rules/a11y.md` |
| Skip link | `#conteudo-principal` in `Layout.astro` | Existing |
| Focus visible | Gold outline via `global.css` `:focus-visible` | Existing |
| Reduced motion | `prefers-reduced-motion` disables all CSS animations + Framer Motion `useReducedMotion()` | Existing |
| Alt text on images | OTB has no `<Image>` components (icon-only via Lucide SVG) | N/A |
| Heading hierarchy | h1 (hero) > h2 (section headings via SectionHeading) > h3 (card titles) | Existing pattern |
| ARIA labels | CTA buttons include `ariaLabel` with product name context | LandingHero pattern |
| Noscript | `[data-reveal]` elements visible when JS disabled | Layout.astro `<noscript>` |
