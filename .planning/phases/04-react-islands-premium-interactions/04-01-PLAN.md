**Core carousel mechanics (per D-10):**
- Track `currentIndex` state with `useState(0)`
- Outer container: `overflow: hidden`, mouse enter pauses autoplay, mouse leave resumes
- Inner track: `m.div` with `drag="x"`, animates `x` position based on `currentIndex * slideWidth`
- `dragDirectionLock` on the draggable element to prevent vertical scroll interference (Pitfall 1)
- `dragElastic={0.1}` for rubber-band feel at edges
- `onDragEnd`: if `offset.x < -50` advance, if `> 50` go back
- Slide transition: `type: "spring", stiffness: 300, damping: 30`
- Wrap-around: when autoplay reaches last slide, loop back to 0

**Slide width calculation (per RESEARCH.md Open Question 1):**
- Use `useRef` on the container + `useState` for measured width
- Measure in `useEffect` on mount + `ResizeObserver` for responsive updates
- Desktop (>=1024px): show 3 cards, each card width = `containerWidth / 3 - gap`. Advance by 1 card width.
- Tablet (>=640px, <1024px): show 2 cards. Advance by 1.
- Mobile (<640px): show 1 card. Advance by 1.
- `dragConstraints`: `{ left: -(maxIndex * slideWidth), right: 0 }`
- Gap between cards: 24px (gap-6)

**Autoplay (per D-10, UI-SPEC):**
- `setInterval` with 4000ms cycle
- Store interval ID in `useRef` (NOT state) to avoid stale closure issues (Pitfall 2)
- Clear on unmount in useEffect cleanup
- Clear on hover/focus enter, restart on leave
- Clear on drag start, restart 8000ms after drag end (per RESEARCH.md recommendation)
- Use functional setState: `setCurrentIndex(prev => (prev + 1) % total)` (Pitfall 6)

**Card styling (per D-13, matching current Testimonials.astro exactly):**
