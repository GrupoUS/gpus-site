## Spacing Scale

Declared values (multiples of 4, inherited from existing site):

| Token | Value | Usage in Phase 4 |
|-------|-------|-------------------|
| xs | 4px | Gap between dot indicators, icon-text inline gaps |
| sm | 8px | Inner padding of dot indicators, gap between avatar initials and text |
| md | 16px | Card internal padding (mobile), gap between carousel cards |
| lg | 24px | Card internal padding (desktop), node-to-node vertical gap (timeline) |
| xl | 32px | Section side padding on mobile (`px-4` = 16px, `sm:px-6` = 24px match existing) |
| 2xl | 48px | WhatsApp button offset from bottom/right on pages with MobileCTABar (`bottom-24`) |
| 3xl | 64px | Section vertical padding (`py-20` = 80px existing pattern; `py-16` = 64px for tighter sections) |

Exceptions:
- WhatsApp floating button: 56px diameter (`h-14 w-14`) -- touch target exceeds 44px minimum.
- MobileCTABar clearance: WhatsApp button uses `bottom-24` (96px) on landing pages with MobileCTABar to avoid overlap. Default: `bottom-6` (24px).
- Timeline progress line width: 2px (`w-0.5`) -- not on the 4px grid; this is a decorative line, not a spacing element.

Source: Existing component patterns in `JourneyTimeline.astro`, `Testimonials.astro`, `MobileCTABar.astro`.

## Animation Contract

### Spring Configurations (Phase 3 continuity)

| Context | Stiffness | Damping | Mass | Source |
|---------|-----------|---------|------|--------|
| Timeline node entrance | 200 | 25 | 1 | Phase 3 HeroEntrance pattern |
| Timeline node stagger delay | 0.12s per node | -- | -- | RESEARCH.md recommendation |
| Progress line scroll tracking | 100 | 30 | -- | useSpring smoothing config |
| Carousel slide snap | 300 | 30 | -- | RESEARCH.md drag pattern |
| WhatsApp button entrance | 260 | 20 | -- | RESEARCH.md code example |
| Dot indicator transition | 200 | 25 | -- | Matches node entrance feel |

### Scroll Offsets

| Element | Trigger | Value | Rationale |
|---------|---------|-------|-----------|
| Timeline progress line | `useScroll` offset | `["start 0.8", "end 0.4"]` | Ensures animation spans viewport travel on tall monitors |
| WhatsApp button entrance | `scrollY` threshold | 400px | Below initial viewport; does not compete with hero CTAs |

### Autoplay

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| Carousel cycle | 4000ms (4s) | CONTEXT.md D-10 locked decision |
| Pause on hover | Immediate (clearInterval) | Standard UX |
| Pause on drag | Immediate (clearInterval) | Prevent competing animations |
| Resume after interaction | 8000ms (8s) delay then restart | RESEARCH.md recommendation -- user needs time to read |

### Reduced Motion

All 3 islands MUST call `useReducedMotion()` from `motion/react`. When true:
- **JourneyTimeline:** Render static vertical layout (all nodes visible, progress line at 100%, no stagger). Equivalent to current `JourneyTimeline.astro` output.
- **TestimonialCarousel:** Render static grid layout (same as current `Testimonials.astro` grid mode). No drag, no autoplay.
- **WhatsAppFloatingButton:** Render immediately visible (no scroll trigger, no spring entrance). Static `scale: 1`.

Source: `.claude/rules/a11y.md`, Phase 3 `MotionReveal.tsx` pattern.

## Component Visual Contracts

### JourneyTimeline.tsx

**Desktop (>=1024px):** Vertical layout. Left side: gold progress line (2px, `scaleY` animated 0->1 via scroll). Right side: 5 staggered node cards in glass-card style. Each node card contains: eyebrow label (text-xs, gold/75, uppercase tracking-widest), stage number (text-3xl, gold/80, Playfair), product name (text-2xl, bold, Playfair, text-primary), stage summary (text-sm, text-muted), product tagline (text-sm, text-muted). Entire card is clickable (`<a>` wrapping) navigating to `pageHref`.

**Mobile (<1024px):** Horizontal scroll-snap carousel. One card visible at a time. Swipe left/right. Progress dots at bottom (5 dots, gold active / gold-30 inactive). Cards maintain glass-card styling.

**Complementary experiences:** Rendered below the timeline as a static text block (same as current `JourneyTimeline.astro` pattern). Not animated.

**Dimensions:** Node card min-height: auto (content-driven). Card padding: `p-6`. Card border-radius: `rounded-3xl`. Gap between nodes: `gap-6`.

### TestimonialCarousel.tsx

**Desktop (>=1024px):** 2-3 cards visible simultaneously. Drag left/right to advance by 1 card. Glass-card `blockquote` elements. Each card: quote icon SVG (h-8 w-8, gold/30), quote text (italic, leading-relaxed, text-primary), footer with avatar initials circle (h-10 w-10, gold gradient bg, gold text) + name (font-semibold, text-primary) + role (text-sm, text-muted). Dot indicators below.

**Mobile (<768px):** Single card visible. Swipe to advance. `dragDirectionLock` enabled to prevent vertical scroll interference.

**Card dimensions:** Same as current `Testimonials.astro` -- `rounded-2xl p-6 md:p-8`. On mobile strip: `w-[min(100vw-2rem,22rem)]`.

**Dot indicators:** Row of circles centered below carousel. Active: `bg-gold w-2.5 h-2.5`. Inactive: `bg-gold/30 w-2 h-2`. Gap: `gap-2`. Clickable (each dot navigates to that slide). `aria-label="Depoimento {n} de {total}"`.

### WhatsAppFloatingButton.tsx

**Position:** `fixed bottom-6 right-6 z-50`. On pages with `MobileCTABar` (landing pages): `fixed bottom-24 right-6 z-50`.

**Size:** 56px diameter (`h-14 w-14`). Round (`rounded-full`).

**Colors:** `bg-whatsapp text-white`. Hover: `bg-whatsapp-hover`. Focus-visible: gold outline (inherits global `:focus-visible` rule).

**Icon:** WhatsApp SVG path (viewBox 0 0 24 24, fill currentColor), 24px (`h-6 w-6`). NOT Lucide MessageCircle.

**Shadow:** `shadow-lg` base. After entrance: `gold-pulse-glow` class applied (desktop only, disabled <768px via existing CSS rule).

**Entrance:** Hidden initially. After 400px scroll: spring scale from 0 to 1 (stiffness 260, damping 20). Once visible, stays visible permanently (no hide on scroll up).

**Accessibility:** `aria-label="Falar com a Laura no WhatsApp"`. `target="_blank" rel="noopener noreferrer"`. Keyboard-focusable `<a>` element.

## Interaction States

### JourneyTimeline Nodes

| State | Visual |
|-------|--------|
| Default | glass-card, card-glow-hover transition |
| Hover | `border-gold/30`, elevated shadow (`shadow-gold/5`), `translateY(-4px)` via card-glow-hover |
| Focus-visible | Gold outline (2px, 2px offset) via global rule |
| Active/pressed | No additional state (standard link behavior) |
| Reduced motion | All nodes visible, no stagger, progress line fully drawn |

### TestimonialCarousel Cards

| State | Visual |
|-------|--------|
| Default | glass-card styling |
| Hover | `border-gold/30`, `shadow-lg shadow-gold/5` (existing Testimonials.astro pattern) |
| Dragging | Elastic resistance at boundaries (`dragElastic: 0.1`), cursor grab/grabbing |
| Reduced motion | Static grid, no drag, no autoplay |

### Dot Indicators

| State | Visual |
|-------|--------|
| Active | `bg-gold w-2.5 h-2.5 rounded-full` |
| Inactive | `bg-gold/30 w-2 h-2 rounded-full` |
| Hover | `bg-gold/60` (inactive dots only) |
| Focus-visible | Gold outline via global rule |

### WhatsApp Floating Button

| State | Visual |
|-------|--------|
| Hidden | `scale: 0`, not in DOM flow (rendered but invisible) |
| Entrance | Spring scale 0->1, then gold-pulse-glow (desktop) |
| Default (visible) | `bg-whatsapp`, `shadow-lg`, gold-pulse-glow animation (desktop) |
| Hover | `bg-whatsapp-hover`, stronger glow shadow |
| Focus-visible | Gold outline (2px, 2px offset) |
| Active/pressed | Standard link behavior |
| Reduced motion | Immediately visible, static glow, no spring entrance |

## Accessibility Checklist (Phase 4 specific)

- [ ] All 3 islands call `useReducedMotion()` and render static fallback
- [ ] Timeline nodes are `<a>` elements (keyboard-navigable, screen-reader accessible)
- [ ] Carousel dot indicators have `aria-label="Depoimento {n} de {total}"`
- [ ] Carousel container has `role="region"` and `aria-label="Depoimentos de alunos"`
- [ ] WhatsApp button has `aria-label="Falar com a Laura no WhatsApp"`
- [ ] WhatsApp button is `<a>` element (keyboard-focusable)
- [ ] Gold-on-navy text meets 4.5:1 contrast (gold #d4af37 on navy #1a1a2e = 7.1:1 -- passes)
- [ ] Gold/30 opacity muted elements are decorative only (progress line, borders), not informational
- [ ] Carousel supports keyboard: arrow keys for navigation, Enter/Space for dot click
- [ ] No content is hidden from screen readers that is visible to sighted users
- [ ] `dragDirectionLock` on carousel prevents scroll hijacking on mobile
