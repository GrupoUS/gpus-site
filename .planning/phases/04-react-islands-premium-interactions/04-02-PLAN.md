**Props interface:**
```typescript
interface WhatsAppFloatingButtonProps {
  message?: string;    // Per-page WhatsApp message. Falls back to WHATSAPP_DEFAULT_SITE_MESSAGE
  hasBottomBar?: boolean; // True on landing pages with MobileCTABar -- raises button position
}
```

**Scroll-triggered entrance (per D-16):**
- Use `useScroll()` (no target -- tracks page scroll) from `motion/react`
- Use `useMotionValueEvent(scrollY, "change", (latest) => { if (latest > 400 && !visible) setVisible(true); })`
- Scroll threshold: 400px (per RESEARCH.md recommendation)
- Once visible, stays visible permanently -- no hide on scroll up
- State: `const [visible, setVisible] = useState(false)`

**Rendering logic:**
- When `!visible && !prefersReducedMotion`: return `null` (not rendered at all)
- When `prefersReducedMotion`: skip scroll check, render immediately with `scale: 1` (no animation). Set initial state `visible = true` or bypass the scroll check entirely by rendering immediately.
- When `visible`: render the `<m.a>` element

**Button element:**
- `<m.a>` (animated anchor from `motion/react-m`) -- NOT a `<button>`, it's a link
- `href={whatsappUrlWithText(message ?? WHATSAPP_DEFAULT_SITE_MESSAGE)}` -- import both from `@/lib/whatsapp`
- `target="_blank"` and `rel="noopener noreferrer"`
- `aria-label="Falar com a Laura no WhatsApp"` (per D-22, UI-SPEC)

**Positioning (per D-21, Pitfall 4):**
- Default: `fixed bottom-6 right-6 z-50`
- When `hasBottomBar` is true: `fixed bottom-24 right-6 z-50` (clears MobileCTABar on mobile)
- Note: MobileCTABar is `md:hidden`, so the offset only matters on mobile. On desktop (>=768px), MobileCTABar is hidden, so `bottom-6` is fine. Use responsive classes: when `hasBottomBar`, use `fixed right-6 z-50 bottom-24 md:bottom-6`

**Sizing (per UI-SPEC):**
- `h-14 w-14` (56px diameter, exceeds 44px touch target)
- `rounded-full`

**Colors (per D-21, using Tailwind tokens):**
- Background: `bg-whatsapp` (#25d366)
- Text/icon: `text-white`
- Hover: `hover:bg-whatsapp-hover` (#20bd5a)
- Shadow: `shadow-lg`

**WhatsApp SVG icon (per D-19):**
- Inline the WhatsApp SVG path (same as in LandingHero.astro, LandingCTA.astro)

**Spring entrance animation (per D-16, UI-SPEC):**
```typescript
initial={{ scale: 0, opacity: 0 }}
animate={{ scale: 1, opacity: 1 }}
transition={{ type: "spring", stiffness: 260, damping: 20, delay: 0.1 }}
```

**Gold pulse glow (per D-18):**
- After entrance animation, apply `gold-pulse-glow` CSS class to the button
- This class is already defined in global.css with `@media (max-width: 768px)` disabling it
- So just add `gold-pulse-glow` to the className -- CSS handles the mobile disable
- On hover, add stronger glow: `hover:shadow-[0_0_20px_rgba(37,211,102,0.4)]`

**Reduced motion (per a11y.md):**
- Call `useReducedMotion()`. If true:
  - Render the button immediately (no scroll check): `const shouldShow = prefersReducedMotion || visible`
  - No spring entrance: `initial={{ scale: 1, opacity: 1 }}`
  - No gold-pulse-glow class (reduced motion CSS already disables it, but skip it defensively)
