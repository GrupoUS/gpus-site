**Create `scripts/smoke-test.mjs` (D-11):**

Create a Node.js ES module script using built-in `fetch()` (Node 22+, no extra deps) that validates:

1. **Configuration:**
   ```javascript
   const BASE = process.argv[2] || 'http://localhost:4321';

   const CONTENT_ROUTES = [
     '/', '/sobre', '/curso-auriculo', '/mentoria-black-neon',
     '/comunidade-us', '/otb', '/neon-dash', '/contato', '/404'
   ];

   const LEGAL_ROUTES = ['/termos', '/politica-de-privacidade'];

   const REDIRECT_ROUTES = [
     { from: '/na-mesa-certa', expectedStatus: 301 },
     { from: '/trintae3', expectedStatus: 301 },
     // Note: comunidade-us and neon-dash are content pages now, not redirects
     // Check astro.config.mjs redirects at time of execution
   ];

   const ASSETS = [
     '/sitemap-index.xml',
     '/robots.txt',
   ];

   const OG_IMAGES = [
     '/og/home.png', '/og/sobre.png', '/og/curso-auriculo.png',
     '/og/mentoria-black-neon.png', '/og/comunidade-us.png',
     '/og/otb.png', '/og/neon-dash.png', '/og/contato.png', '/og/404.png'
   ];
   ```

2. **Content route checks:** For each route in CONTENT_ROUTES + LEGAL_ROUTES:
   - `fetch(BASE + route)` with no redirect following
   - Expect HTTP 200
   - Verify response body contains `</html>` (valid HTML page)
   - Log result: `[PASS] / — 200` or `[FAIL] /sobre — 404`

3. **Redirect checks:** For routes in REDIRECT_ROUTES:
   - `fetch(BASE + route, { redirect: 'manual' })`
   - Expect HTTP 301 or 302
   - Verify `Location` header exists
   - Do NOT follow the redirect to external URLs (avoid network dependency on external sites)
   - Log: `[PASS] /na-mesa-certa — 301 -> https://namesa.gpus.com.br`

4. **Asset checks:** For sitemap-index.xml and robots.txt:
   - `fetch(BASE + asset)`
   - Expect HTTP 200
   - For robots.txt: verify body contains `Disallow: /404`
   - For sitemap-index.xml: verify body contains `<sitemapindex` (valid sitemap)

5. **OG image checks:** For each OG image:
   - `fetch(BASE + image, { method: 'HEAD' })`
   - Expect HTTP 200
   - Verify content-type starts with `image/`
   - Log: `[PASS] /og/home.png — 200 (image/png)` or `[FAIL] /og/sobre.png — 404`

6. **Summary output:**
   ```
   === Smoke Test Results ===
   Content Routes:  11/11 passed
   Redirects:       2/2 passed
   Assets:          2/2 passed
   OG Images:       9/9 passed

   Total: 24/24 passed — ALL OK
   ```
   Or on failure:
   ```
   Total: 22/24 passed — 2 FAILURES

   Failures:
   - /og/sobre.png — Expected 200, got 404
   - /termos — Expected 200, got 500
   ```

7. **Exit code:** 0 on all pass, 1 on any failure.

8. **Timeout:** Each fetch has a 10-second timeout via `AbortController`. If a request times out, log `[FAIL] /path — TIMEOUT (10s)`.
