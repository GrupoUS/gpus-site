**Create `scripts/lighthouse-audit.mjs` (D-04):**

Create a Node.js ES module script that:

1. **Configuration constants:**
   ```javascript
   const PAGES = [
     '/', '/sobre', '/curso-auriculo', '/mentoria-black-neon',
     '/comunidade-us', '/otb', '/neon-dash', '/contato', '/404'
   ];
   const THRESHOLD = 95;
   const CATEGORIES = ['performance', 'accessibility', 'best-practices', 'seo'];
   const BASE_URL = process.argv[2] || 'http://localhost:4321';
   ```

2. **Chrome launch:** Use `chrome-launcher` to launch headless Chrome with `--headless=new` and `--no-sandbox` flags. Store the chrome instance for cleanup.

3. **Per-page audit function:** For each page in PAGES:
   - Build full URL: `${BASE_URL}${page}`
   - Run `lighthouse(url, { port: chrome.port, output: 'json', onlyCategories: CATEGORIES, preset: 'desktop' })`
   - Extract scores: `Math.round(result.lhr.categories[cat].score * 100)` for each category
   - Return `{ page, scores, pass: allScoresAboveThreshold }`

4. **Score variance handling (per RESEARCH.md Pitfall 1):** Use `--preset=desktop` for less variance. If a page fails on first run, re-run up to 2 more times (3 total) and take the BEST score per category. Document this retry behavior in console output.

5. **Output:** Print a summary table to stdout:
   ```
   Page                    | Perf | A11y | BP   | SEO  | Status
   /                       |  98  |  100 |  100 |  100 | PASS
   /sobre                  |  96  |  100 |  100 |  100 | PASS
   ...
   ```
   Use aligned columns. Color PASS green, FAIL red (using ANSI codes).

6. **Exit code:** Exit 0 if ALL pages pass ALL categories >= THRESHOLD. Exit 1 if ANY page fails ANY category after retries. Print the failing pages/categories before exit.

7. **Chrome cleanup:** Always call `chrome.kill()` in a finally block.

8. **Error handling:** If Chrome is not found, print a clear error message:
   ```
   Error: Chrome not found. Install Chrome in WSL:
   wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb && sudo apt -y install ./google-chrome-stable_current_amd64.deb
   ```

9. **CHROME_PATH support:** At the top of the script, check `process.env.CHROME_PATH` and pass it to `chrome-launcher` if set. Default: let chrome-launcher auto-detect.

Install lighthouse and chrome-launcher as devDependencies:

- Document any page that cannot reach 95 with reasoning
