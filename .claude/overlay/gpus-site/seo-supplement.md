# SEO Supplement — Grupo US · Site Institucional

> Loaded by `performance-optimization` skill (`seo-geo-baseline` pack).

## Locale

`pt-BR`. Every public page sets `<html lang="pt-BR">` (wired in `src/layouts/Layout.astro`).

## Routes (all prerendered)

| Route | Type | SEO requirements |
|---|---|---|
| `/` | static | OG image, JSON-LD `Organization` (canonical `https://grupous.com.br`), title ~60 chars, description ≥120 chars |
| `/sobre` | static | OG image, BreadcrumbList Home → Sobre, narrative description (Dra. Sacha + ecossistema) |
| `/contato` | static | OG image, BreadcrumbList, contact intent (direct WhatsApp CTA) |
| `/curso-auriculo` | static | per-product `ogImage` (`d.image`); FAQ JSON-LD recommended |
| `/mentoria-black-neon` | static | high-ticket positioning, vagas/ciclo language in description |
| `/trintae3` | static *or* redirect | check `astro.config.mjs::redirects` to avoid double-indexing if both exist |
| `/comunidade-us`, `/neon-dash`, `/na-mesa-certa`, `/otb` | redirect | 301 → external; sitemap `filter()` excludes |
| `/{termos,politica-de-privacidade}` | static | minimal description, no `noindex` |
| `/404` | static | `<meta name="robots" content="noindex">` |

> **Double-source rule:** if a slug exists both as `.astro` AND as `redirects` entry, the redirect wins at runtime. Remove the `.astro` once the redirect is canonical, OR remove the redirect once the local page is canonical.

## Sitemap

Generated by `@astrojs/sitemap` at build time. `filter()` excludes redirect-only paths: `/comunidade-us`, `/neon-dash`, `/na-mesa-certa`, `/trintae3` (when canonical destination is external), `/otb`. Add to `filter` in the same commit that adds a new redirect.

Rebuild: `bun run build` regenerates `dist/sitemap-index.xml`.

## robots.txt

## OG / Twitter cards

`Layout.astro` props: `og:title`, `og:description`, `og:image` (1200×630, default `/og-image.png`), `og:locale=pt_BR`, `og:type=website`. `twitter:card=summary_large_image`. Per-product landing: pass `ogImage={d.image}`.

> **Action:** ensure `public/og-image.png` exists. Without it, every page lacking explicit `ogImage` falls back to a 404.

## JSON-LD

`Organization` (every page, via `Layout.astro`):

```json
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "Grupo US",
  "url": "https://grupous.com.br",
  "logo": "https://grupous.com.br/images/logo.png",
  "sameAs": ["https://www.instagram.com/drasachagualberto"],
  "contactPoint": {
    "@type": "ContactPoint",
    "telephone": "+55-62-9470-5081",
    "contactType": "sales",
    "areaServed": "BR",
    "availableLanguage": ["Portuguese"]
  }
}
```

`BreadcrumbList` (product landings + legal pages):

```json
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    { "@type": "ListItem", "position": 1, "name": "Home", "item": "https://grupous.com.br" },
    { "@type": "ListItem", "position": 2, "name": "<page name>", "item": "<page url>" }
  ]
}
```

## CWV thresholds

Per `.claude/config.json::gates`: LCP < 2.5s · CLS = 0 · INP < 100ms · Initial JS < 50KB.

Strategies: hero `<Image loading="eager" fetchpriority="high">`; preconnect Google Fonts; explicit `width`/`height`; `client:visible`/`client:idle` (never `client:load` for non-LCP).

## AI citation (GEO)

- Each product `description` ≥ 120 chars and unique — feeds `<meta name="description">` and AI search snippets.
- `tagline` ≤ 90 chars — distills core promise.
- `cta.url` must resolve (drasacha funnel or external) — broken CTAs hurt LLM citation confidence.
- Prefer pt-BR phrasing aligned with `grupo-us` skill voice: "Nós iluminamos", "Olhar de dono", "Clareza é a nova gentileza".
- Avoid client-only-rendered SEO fields — every meta is server-rendered (Astro static).
