# Path rules: `src/components/`, `src/styles/global.css`, `src/layouts/Layout.astro`

SSOT: `AGENTS.md` (a11y section). Operational checks before merge.

- **Contrast:** ≥ 4.5:1 normal text, ≥ 3:1 large text (WCAG AA) on navy/gold palette.
- **Focus:** `:focus-visible` uses gold outline in `global.css` — keep interactive elements keyboard-reachable.
- **Skip link:** `.skip-link` targets `#conteudo-principal`; `<main id="conteudo-principal" tabindex="-1">` must remain.
- **Controls:** `aria-label` (or visible text) on icon-only buttons; meaningful `alt` on informative images (who + role).
- **Headings:** One `h1` per page in hero; `h2` sections, `h3` items — no skipped levels.
- **Motion:** `prefers-reduced-motion` in `global.css` disables CSS reveal animations; Framer Motion islands must use `useReducedMotion()`.
- **No-JS:** `<noscript>` in `Layout.astro` keeps `[data-reveal]` visible — do not remove without replacement.
- **FAQ:** Native `<details>`/`<summary>` or CSS grid `0fr`/`1fr` — no height tween accordions.
- **Legal links:** `/termos`, `/politica-de-privacidade` — never `href="#"`.
- **Smoke test:** Tab through header (mobile menu) and FAQ before committing large UI changes.
